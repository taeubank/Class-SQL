# Class-SQL

An educational SQL repository covering core SQL concepts with practical examples.

## Contents

| File | Topic |
|------|-------|
| [01_create_tables.sql](01_create_tables.sql) | DDL – Creating tables and defining constraints |
| [02_insert_data.sql](02_insert_data.sql) | DML – Inserting rows |
| [03_select_queries.sql](03_select_queries.sql) | Basic SELECT statements and filtering |
| [04_joins.sql](04_joins.sql) | INNER, LEFT, RIGHT, and FULL OUTER JOINs |
| [05_aggregations.sql](05_aggregations.sql) | GROUP BY, HAVING, and aggregate functions |
| [06_subqueries.sql](06_subqueries.sql) | Subqueries and derived tables |
| [07_update_delete.sql](07_update_delete.sql) | Updating and deleting rows |
| [08_indexes_views.sql](08_indexes_views.sql) | Indexes and views |

## Getting Started

Any SQL-compatible database (PostgreSQL, MySQL, SQLite, etc.) can be used to run these examples.  
Run the scripts in order – each file builds on the tables and data created by the previous ones.
